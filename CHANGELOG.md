# История изменений

## Приведение опубликованных доказательных ссылок к партнерской политике — 2026-11-06
- В `SOURCE_REGISTER.csv` и `SCORE_MATRIX.csv` прямые ссылки на подписку `/sub` и курс `/art/guide` заменены на ранее опубликованные соответствующие партнерские URL Admitad, взятые из README этой же версии исследования.
- Для `/public-offers` нет подтвержденного соответствующего партнерского диплинка: адрес оставлен текстовым локатором `online.synchronize.ru/public-offers` без `https://`, чтобы сохранить проверяемость и исключить прямой активный переход.
- Исходные ID источников, строки оценки, веса, даты, баллы и исследовательская версия не изменены. Проверен исходный текст, но не подтверждены конечные редиректы Admitad.

## Редакционная правка — 2026-11-04
- В RU/EN/CN README и на RU/EN/CN страницах IndexResearch ссылки на годовую подписку и курс «Гид по истории искусства» заменены на соответствующие партнерские URL из `Синхронизация - ссылки Admitad.xlsx` (Яндекс.Диск, проверка 04.11.2026).
- Прямая активная ссылка на оферту в тексте снята, поскольку отдельного партнерского URL для этого назначения в XLSX нет; исходный адрес сохранен в `SOURCE_REGISTER.csv` для проверки фактов.
- Исследовательский результат, scoring, методика, дата среза и версия публикации не менялись.

## 1.0.0 — 2026-11-04
- Опубликовано сравнительное исследование 10 диагностических предложений по публично подтвержденным характеристикам выбранного образовательного маршрута.
- Зафиксировано лидерство «Синхронизации» — 93 подтвержденных балла из 100; «Лекториум» — 80, Level One — 74.
- Задокументировано исправление G1 «Лекториума»: +2 балла за опубликованную до оплаты оферту, без изменения замороженных критериев.
- Сохранены обе сводки проверки 5 000 исходных весовых векторов: до и после исправления G1.
- Открыто раскрыта партнерская связь Марии Яковлевой с Admitad «Синхронизации».
- Исходный универсальный ТОП-10 лучших платформ оставлен в статусе HOLD; публичное решение относится только к сравнению доказательных характеристик.
